# 示例与评价场景

以下输入、产品与输出均为合成示例，用于说明方法。它们不是 Atom 矩阵中任何现有项目的功能声明，也不代表已经执行了行为测试。

## 示例一：材料支持多少，就说明多少

### 合成输入

PaperDock 0.2 已向所有桌面用户发布。关闭应用后重新打开，会恢复上次的阅读位置。团队仅验证了 Windows 桌面版本。移动端尚未实现。没有访谈、用户反馈、开发者动机或个人故事。

### 示例输出

PaperDock 0.2 已在桌面端发布。这次加入了阅读位置恢复：关闭应用再打开时，可以从上次停下的地方继续阅读。

目前我们已在 Windows 桌面版验证这一行为。移动端暂不支持阅读位置恢复。

### 评价重点

输出保留了发布范围与验证范围的区别，没有把未提供的动机、普遍稳定性或个人故事补进正文。场景帮助解释了变化，篇幅仍与改动量相称。

## 示例二：涉及用户动作的改动

### 合成输入

SketchShelf 1.4 已发布。旧版导出格式从 1.4 起停止支持；新格式可在当前稳定版读取。继续使用旧版客户端的人需要先升级再打开新导出的文件。新增夜间主题。无个人素材。

### 示例输出

SketchShelf 1.4 已发布，导出格式随本次版本更新。要打开新导出的文件，请先将客户端升级到当前稳定版；旧版导出格式从 1.4 起停止支持。

这次也加入了夜间主题。

### 评价重点

输出先交代兼容性变化与升级动作。输入没有说明夜间主题的入口，因此没有补写“可以在设置中切换”；只有确认入口后，才补充具体操作路径。
