## 下一轮实践

已在 0.2.0 补充 [资料索引](SOURCES.md)、Apple 排版学习笔记、Railcode 创作过程笔记、The Type 西文阅读地图，以及参考驱动的设计 draft skill。资料整理与方法草案已完成；下面的实际尝试仍需逐项积累。

- [ ] 用首个 skill 完成一次真实产品更新说明，记录结果和反馈。
- [ ] 从真实 App 或设计任务中积累一个可比较的案例，解释视觉与交互取舍。
- [ ] 建立第一份 taste 比较笔记，让评价对应具体选择与使用语境。
- [ ] 在一个真实页面中尝试排版检查，记录渲染环境和前后效果。
- [ ] 按当前任务从 The Type 阅读地图中选读文章，分别记录具体结论与来源。
- [ ] 根据实践结果修订方法，避免把单个来源扩写成普遍规则。

## 后续方向

人文阅读与叙事、艺术观察与视觉表达、App 原型与体验、跨领域灵感迁移，以及科研问题构建与概念表达，都可以从具体任务逐步生长。需要时再增加分类、索引或自动化。

科研创造性方法的成果应同时记录灵感来源和证据需求；真实研究材料公开前需单独确认披露范围。
