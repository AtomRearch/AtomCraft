# AtomCraft

**A growing practice of creativity, taste, and making.**

[中文说明](README.zh-CN.md)

AtomCraft is part of the [AtomRearch](https://github.com/AtomRearch) matrix: a public collection of learning notes, reusable AI skills, and workflows for creative work. It connects humanities, art, design, app making, writing, and creative scientific practice.

The aim is to turn encounters with good work into better decisions and things worth making. Taste develops through close observation, explicit choices, practice, and revision. A useful method should preserve room for the creator's judgment.

## Scope

- Humanities and expression: reading, interpretation, narrative, cultural context, and writing.
- Art and design: visual language, composition, typography, interaction, and aesthetic judgment.
- Apps and products: concepts, prototypes, interfaces, onboarding, and product communication.
- Taste: comparative critique, contextual judgment, tradeoffs, and learning from references.
- Creative research: question framing, conceptual models, explanation, and scientific storytelling, with evidence tracked separately from speculation.
- Workflows: practical combinations of tools, people, and AI across these activities.

These are directions for growth. The current library contains four source notes (including one directory-level reading map), two draft skills, and two workflows. The broader directions will grow through concrete tasks and documented feedback.

The [source index](docs/SOURCES.md) distinguishes articles read from reading queues. It also links SkyWT's existing Chinese typography skill for upstream reuse; that external skill is not bundled or installed here.

## Use a skill

Open a skill's `SKILL.md` and give it to your assistant together with the actual task and materials. For an assistant with repository access:

> Read `skills/human-centered-release-notes/SKILL.md`, then draft release notes from these verified changes: …

Read linked references only when needed. Repository skills are ordinary Markdown files; cloning this repository does not automatically install or activate them in an assistant. You can also follow their instructions yourself.

## Develop the practice

Start with a concrete work or problem. Record what you observed, identify a transferable choice, try it on an actual task, and keep the evidence that changes your judgment. [The workflow](workflows/learn-to-craft.md) explains this loop. [Contributing](CONTRIBUTING.md) describes how to add and revise entries.

Skills progress from **draft** to **tried** to **refined** through documented use. A convincing example alone is not evidence of real-world validation.
