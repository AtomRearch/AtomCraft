# AtomCraft

**关于创造力、taste 与动手实践的长期方法库。**

[English](README.md)

AtomCraft 是 [AtomRearch](https://github.com/AtomRearch) 矩阵的一部分，持续积累人文、艺术、设计、App、写作，以及科研创造性实践中的学习笔记、AI skills 和 workflows。

我们希望把遇见的好作品、好方法，转化成可以解释、实践和修订的能力。Taste 在观察、选择、制作与反馈中逐步形成；方法为创作者的判断提供支持，也给探索留下空间。

## 长期范围

- **人文与表达**：阅读、诠释、叙事、文化语境与写作。
- **艺术与设计**：视觉语言、构图、字体、交互与审美判断。
- **App 与产品**：概念、原型、界面、引导流程与产品沟通。
- **Taste**：比较作品，说明偏好与取舍，理解一种选择适合什么语境。
- **科研创造性实践**：问题构建、概念模型、解释与科学叙事；明确区分证据、类比、假说和推测。
- **工作流**：围绕上述活动组合工具、人与 AI，保留实际有帮助的过程。

以上是发展方向。当前库中有四份来源笔记（包含一份目录层面的阅读地图）、两个 draft skills，以及两个 workflows；其他方向将随真实任务与反馈逐步生长。

[资料索引](docs/SOURCES.md) 分别记录已读文章与待读条目，也保留 SkyWT 已有中文排版 skill 的上游入口；该外部技能未被打包或安装到本仓库。

## 如何使用

把某个 skill 的 `SKILL.md` 与具体任务、真实素材一起交给 AI，也可以自行照着使用。例如：

> 读取 `skills/human-centered-release-notes/SKILL.md`，根据下面这些已确认的产品改动，写一期中文更新说明：……

按任务需要读取它链接的参考资料。克隆仓库不会自动把 skills 安装或启用到任何客户端。

## 如何成长

遇到值得学习的作品时，先记录出处与具体观察，再提炼可迁移的判断，在真实任务中尝试，依据反馈修订。详见 [workflow](workflows/learn-to-craft.md) 和 [贡献说明](CONTRIBUTING.md)。

Skill 使用 **draft → tried → refined** 表达成熟度，每次升级都需要使用记录。示例可以帮助理解方法；真实使用效果需要另外记录。
