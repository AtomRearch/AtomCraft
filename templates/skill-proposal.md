# Skill 提案模板

这是提案模板，完成后再创建实际的 `skills/<name>/SKILL.md`。按任务保留有用字段。

| 字段 | 需要说明的内容 |
| --- | --- |
| 名称 | 简短、可发现的 lowercase-hyphenated-name |
| 任务 | 谁在什么情境下需要完成什么 |
| 输入 | 必要素材，哪些信息可以缺省，哪些缺失影响准确性 |
| 判断 | 哪些非显然的选择会改善结果 |
| 工作方式 | 把素材转化为输出的实用指导，保留探索空间 |
| 输出 | 使用者最终拿到什么 |
| 质量标准 | 如何观察任务是否完成、作品是否适用 |
| 边界 | 哪些条件下不应迁移，或需要其他方法 |
| 来源 | 来源链接、自己的延伸、已有实践证据 |
| 成熟度 | 从 draft 开始，升级依据见 CONTRIBUTING.md |

复杂示例或条件性细节可以放到 skill 的 `references/` 中，从 `SKILL.md` 链接。只有实际需要重复执行的操作，才添加脚本或依赖。
